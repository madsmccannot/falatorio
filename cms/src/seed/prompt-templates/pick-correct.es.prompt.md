# Pick-Correct Exercise Generator — Spanish (ES)

Generate pick-correct exercises for Spanish-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- False friends are the primary challenge — build distractors from ES-PT false friends:
  - exquisito (PT: esquisito = strange), embarazada (PT: embaracada ≠ pregnant in same usage), largo (PT: largo = wide, not long), oficina (PT: oficina = workshop, not office), vaso (PT: vaso = vase, not glass)
- Spanish speakers over-transfer verb forms — test ser/estar, por/para, ir+a vs ir+infinitive
- PT-EU has personal infinitive, Spanish does not — test this at B1+
- Clitic placement differs — PT-EU prefers enclisis, Spanish proclisis. Test placement rules
- PT-EU uses gerund differently from Spanish — estar a + infinitive vs estar + gerundio
- Include distractors that are correct in Spanish but incorrect in PT-EU
- tu/voce distinction in PT-EU differs from tu/usted — test appropriate register
- Subjunctive triggers differ between ES and PT — test futuro do conjuntivo (does not exist in ES)
