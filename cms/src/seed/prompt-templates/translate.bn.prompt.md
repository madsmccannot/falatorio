## L1-Specific Rules
- Bengali has SOV word order; PT has SVO — emphasise word order in translations
- Bengali has postpositions; PT has prepositions — highlight prepositional usage
- Bengali has grammatical gender but only for animate nouns — PT applies gender to all nouns, drill this
- Bengali lacks articles — drill o/a/os/as usage in every translation
- Bengali speakers in Portugal often work in restauracao and comercio — include practical vocabulary for these sectors
- Bengali has aspirated consonants not present in PT — note pronunciation differences in tips
- Include context sentences relevant to the Bangladeshi community in Portugal: residencia, trabalho, SEF/AIMA, escola
- Bengali script (Bangla) is not Latin — keep A1-A2 translations shorter and with phonetic support
- Use English as bridge language for technical terms when helpful
