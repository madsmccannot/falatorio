# Fill-in-the-Blank Exercise Generator — Hindi (HI)

Generate fill-in-the-blank exercises for Hindi-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- Hindi has no articles — test article selection (o, a, os, as, um, uma) as blank targets
- Hindi has different gender assignment — test gender agreement (adjective + noun + article)
- Hindi has postpositions, PT has prepositions — test preposition selection (a, de, em, por, para, com)
- Hindi uses SOV; PT uses SVO — test word order when filling blanks in longer sentences
- Hindi lacks subjunctive — at B1+ test conjuntivo triggers with blanks
- Hindi verb system differs significantly — test ser/estar, ter/haver, ficar distinctions
- Distractors should include errors typical of Hindi speakers: wrong gender, missing article, wrong preposition
- Include practical vocabulary from daily life in Portugal (compras, transportes, saude)
