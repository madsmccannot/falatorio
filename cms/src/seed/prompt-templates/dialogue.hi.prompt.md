# Dialogue Exercise Generator — Hindi (HI)

Generate dialogue-based exercises for Hindi-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- Hindi speakers are familiar with formal/informal register distinction (aap/tum/tu) — bridge to PT voce/tu
- Include scenarios relevant to the Indian/South Asian community in PT: restaurante indiano, loja de especiarias, escola dos filhos, consulta medica, documentacao/AIMA
- Hindi has jugaad culture — bridge to Portuguese "desenrascar" concept in dialogues
- Cricket references can be used as cultural bridges for informal dialogues
- Chai/cha connection — use the tea/coffee culture bridge between Hindi and Portuguese
- Bollywood references can make dialogues feel familiar and less alienating
- Hindi speakers tend to use overly formal register initially — include dialogues that teach when to use tu vs voce
- Include dialogues about Portuguese cultural situations: festa de santos populares, praia, cafe, mercado
- Politeness markers differ — Hindi uses "ji", PT uses conditional (queria, gostaria)
