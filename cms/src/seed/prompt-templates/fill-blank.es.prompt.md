Generate fill-in-the-blank exercises for Spanish-speaking learners of European Portuguese (PT-EU).

Same as default template.

## L1-Specific Rules
- Test ser/estar usage differences between ES and PT — contexts where PT uses estar but ES uses ser, and vice versa
- Test por/para — mapping differs from Spanish por/para
- Test personal infinitive blanks — structure unique to PT that Spanish lacks
- Test future subjunctive (futuro do conjuntivo) — extinct in Spanish, alive in PT-EU
- Test estar a + infinitive vs gerund — PT-EU uses "estou a fazer", not "estou fazendo"
- Distractors should be forms that are correct in Spanish but wrong in PT: "estoy haciendo" calque, wrong clitic position
- Test clitic placement — PT-EU enclisis vs ES proclisis in affirmative sentences
- False friend traps as distractors: esquisito, oficina, constipado, propina
- At C1+: test mesoclisis (dar-lho-ei), literary pluperfect (fizera)
