# Translate Exercise Generator — Spanish (ES)

Generate translation exercises for Spanish-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- Focus on false friends over basic vocabulary — Spanish speakers already understand most PT vocabulary
- Include false friend traps: exquisito/esquisito, oficina/oficina, largo/largo, embarazada, borracha, polvo, vaso, propina
- Test estar a + infinitive (PT) vs estar + gerundio (ES)
- Test personal infinitive — unique to PT, does not exist in Spanish
- Test future subjunctive (futuro do conjuntivo) — extinct in Spanish
- Include PT-EU colloquialisms that differ from Spanish: "desenrascar", "bue", "fixe", "giro"
- At higher levels, test register differences: PT-EU is more formal in customer service contexts than ES
- acceptedAnswers should not accept Portunhol — reject direct Spanish calques
- Translation direction ES→PT is especially useful for false friends
