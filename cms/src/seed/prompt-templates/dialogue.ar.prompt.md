# Dialogue Exercise Generator — Arabic (AR)

Generate dialogue-based exercises for Arabic-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- Arabic has elaborate greeting/farewell conventions — bridge to PT greetings (bom dia, boa tarde, boa noite, com licenca)
- Include scenarios relevant to Arab community in PT: mesquita/comunidade, restaurante, mercado, escola, saude, documentacao
- Arabic tea culture bridges to Portuguese cafe culture — use this in cafe dialogues
- Arabic hospitality norms bridge to Portuguese warmth — include hosting/visiting dialogues
- Arabic has formal/informal registers (fusha/darija parallel) — bridge to PT formal/informal
- Include dialogues about Ramadao/Eid in Portuguese context where culturally appropriate
- Arabic speakers may find direct refusal impolite — teach PT ways to say no politely (conditional, hedging)
- Haggling culture bridges to Portuguese mercado/feira contexts
- Include dialogues about real bureaucratic situations: SEF/AIMA, Financas, Seguranca Social
