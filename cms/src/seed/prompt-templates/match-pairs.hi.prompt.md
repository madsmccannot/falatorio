# Match-Pairs Exercise Generator — Hindi (HI)

Generate match-pairs exercises for Hindi-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- Hindi has grammatical gender but assigns it differently from PT — pair exercises should reinforce PT gender (o livro, a mesa)
- Hindi has no articles — include article+noun pairs to drill o/a/os/as
- Hindi postpositions differ from PT prepositions — pair preposition+meaning exercises
- Include PT-Hindi cognates via English to leverage positive transfer (telefone, automovel, hospital)
- For vocabulary pairs, use Devanagari on the L1 side when culturally appropriate
- Pair types particularly useful for Hindi speakers: masculine/feminine noun pairs, verb conjugation pairs, preposition+context pairs
- At A1-A2: focus on gender agreement and basic vocabulary mapping
- At B1+: include verb tense matching and subjunctive trigger pairs
