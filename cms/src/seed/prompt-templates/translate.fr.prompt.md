Generate translation exercises for French-speaking learners of European Portuguese (PT-EU).

## L1-Specific Rules
- French and PT share many cognates via Latin — leverage these but flag false friends
- French nasal vowels partially transfer — but PT-EU nasals are different, note distinctions
- Subjunctive (subjonctif) exists in French — bridge this knowledge but test different triggers in PT
- French lacks personal infinitive — test this at B1+
- Gender often differs: FR le lait (masc) → PT o leite (masc, same); FR la mer (fem) → PT o mar (masc, different)
- French speakers tend to over-nasalise — translation exercises should include pronunciation tips
- PT-EU reduced vowels are unfamiliar to French speakers used to full vowel pronunciation
- Test ser/estar distinction (French only has etre) and por/para (French par/pour map differently)
- Include false friends: FR assister = PT assistir (both exist but usage differs), FR constiper ≠ PT constipar
