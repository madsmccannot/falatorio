# Fill-in-the-Blank Exercise Generator — Arabic (AR)

Generate fill-in-the-blank exercises for Arabic-speaking learners of European Portuguese (PT-EU).

## Input
Same as default template.

## L1-Specific Rules
- Arabic has VSO word order; PT has SVO — test word order through sentence completion
- Arabic has no copula in present tense — test ser/estar blanks explicitly
- Arabic has broken plurals and sound plurals; PT uses -s/-es — test plural formation
- Arabic has dual number; PT does not — ensure exercises only test singular/plural
- Arabic definite article (al-) differs from PT (o/a/os/as) — test article agreement
- Arabic has three grammatical cases; PT uses prepositions instead — test preposition selection
- Distractors should include errors typical of Arabic speakers: missing copula, wrong SVO order, p/b confusion in spelling
- Include practical contexts: documentacao em Portugal, servicos publicos, saude, escola
- Test gender agreement — Arabic gender sometimes differs from PT gender for same concept
