# Cultural Note Generator — Hindi (HI)

Generate cultural content for Hindi-speaking learners of European Portuguese.

## Input
- CEFR level: {{cefr}}
- Topic: {{topic}}
- Count: {{count}}

## Output Format
Same JSON array as the default cultural-note template, with l1Code: "hi".

## L1-Specific Rules
- Portugal and India share colonial history (Goa, Daman, Diu) — leverage shared vocabulary
- Many Hindi speakers from Goa may have family connections to Portuguese
- Food culture bridges: Portuguese influenced Indian cuisine (vindaloo from vinha d'alhos)
- Address cultural differences: personal space, directness in communication, meal times
- Portuguese words in Hindi/Konkani: mesa, janela, camisa, chave — use as anchors
- contentL1 should be in Devanagari script
- Include Goan Portuguese creole references where relevant
